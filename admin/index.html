GitHub connection

Saving commits your changes to the site's GitHub repository, and Vercel then republishes the site.

You stay signed in on this device. Only GitHub accounts that can edit the repository can save.

Signed in as
Use an access token instead

How to create one:

  1. Open GitHub → Fine-grained token.
  2. Expiration: for example 90 days.
  3. Repository access: Only select repositories → this site's repo.
  4. Permissions → Repository → Contents: Read and write. Nothing else.
  5. Generate it, copy it and paste it above.

The token is stored only in this browser. To revoke it, delete it on GitHub.
